# 🏎️ PIT WALL - GP de São Paulo (F1)

O **PIT WALL** é uma landing page temática de Fórmula 1 desenvolvida com foco no **GP de São Paulo em Interlagos**. O projeto apresenta informações sobre o evento, grid de pilotos, tabela de classificação em tempo real (simulada) e um formulário interativo de reserva de ingressos.

## ⚙️ Funcionalidades

- **Hero Banner:** Área principal em destaque com estatísticas da pista de Interlagos e chamada para ação (CTA).
- **Grid de Pilotos:** Cards estilizados inspirados na identidade visual das transmissões de F1 (Ferrari, Mercedes, Red Bull, etc.).
- **Tabela de Classificação:** Tabela responsiva com estatísticas da temporada e filtro de busca por piloto ou equipe.
- **Reserva de Ingressos:** Formulário de checkout e reserva completo, permitindo seleção de setor, envio de recados e upload de fotos da torcida.
- **Design Responsivo:** Layout adaptado para visualização em desktops, tablets e dispositivos móveis.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estrutura semântica e acessível.
- **CSS3:** Estilização moderna com variáveis CSS (`:root`), Grid Layout, Flexbox, gradientes customizados e responsividade via Media Queries.
- **Google Fonts:** Tipografia temática utilizando a fonte *Titillium Web*.
